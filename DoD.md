## Definition of Done
- For any work to be considered done the following all conditions must be met:

   - Peer reviewed: The group must collectively agree with the changes.

   - Quality Work: All work must be up to standard and good quality

   - Merged into database: The code must be successfully merged into the GitHub repository with Pull Request.

   - Does not break the project: When executed, the program must run successfully with no website breaking errors on any supported platforms.

   - Passes all required automated tests.
